# 자체 카드 그림 수정 가이드

v0.32는 364개의 자체 제작 판타지 회화형 이미지를 관리한다. 인터넷에서 원본 카드 PNG를 불러오지 않는다. 그림과 실제 카드 규칙이 서로 분리되어 있다.

## 그림 확인

- `card-gallery.html`: 전체 380종의 그림, 카드 이름, 능력치와 문구를 한 번에 확인하는 도감. 이름·효과·ID 검색과 등급 필터를 사용한다. 영웅 등급을 선택하면 38종만 표시된다. 파일을 더블클릭하고 마우스를 1초간 올려 확대한다.
- `interface-preview.html`: 실제 React UI에서 생성된 전장·최대 손패·덱 편집·카드 디자인 샘플. 1초 확대 및 카드 세트 탭 체험 가능.
- `interface-quick.html`: 전투 장면과 사용한 그림만 내장한 작은 React 정적 HTML. 설치 없이 1초 확대 체험 가능.
- `previews/battle-layout.png`, `previews/card-hover.png`: HTML이 열리지 않을 때 확인할 수 있는 정적 화면 배치 이미지(브라우저 캡처 아님).
- `previews/illustrations.jpg`, `previews/illustrations-all.jpg`: 대표 20종 및 전체 364종 일러스트 모음 이미지.
- `previews/illustrations-epics-all.jpg`, `previews/illustrations-classic.jpg`: 영웅 카드 관련 40종과 신규 기존 카드 전용 50종 그림 모음.
- `previews/illustrations-comparison.jpg`: 이전 v0.29와 v0.30의 포인트 강조 비교(대표 6종).
- `previews/card-frame-comparison.png`: 같은 원본 그림으로 기존 가로로 긴 칸과 개선된 정사각형 칸을 비교한 정적 배치 이미지.
- `previews/illustrations-distinct.jpg`: v0.32에서 새로 제작한 중복 제거용 일러스트 149종.
- `previews/illustrations-comparison-v031.jpg`: v0.30과 v0.31의 야수·용·화염·빙결·골렘·악마 포인트 강조 비교(대표 6종).
- `start-game.cmd`: 실제 플레이(첫 npm 설치 후에는 이미지 인터넷 연결 불필요).

## 카드 수치 수정

기존 `start-balance.cmd`를 실행하고 비용·공격력·생명력·효과를 수정한다. 그림은 카드 ID에 따라 결정되므로 동일한 ID의 밸런스를 수정해도 그대로 유지된다. 새 카드도 ID와 종류를 기준으로 자동으로 그림을 할당한다.

## 특정 카드의 그림을 바꾸고 싶다면

`apps/client/src/painted-art-model.ts` 파일의 PAINTED_OVERRIDES 표가 개별 그림 연결을 관리한다. 예를 들어 `flame_sphere: 'fire'`는 화염구에 불덩이 그림을 연결한다. `PAINTED_ASSETS`의 목록에서 파일명을 확인해 변경하고 게임을 재실행한다. 카드 엔진 데이터 파일은 별도로 백업된다. 특정 연결이 없으면 `local-art-model.ts`의 53개 주제 분류와 안정적인 카드 ID 시드를 이용해 알맞은 회화형 그림을 선택한다.

그림 파일은 `apps/client/src/assets/illustrations/`에 있으며, 300×300 카드 관련 그림 355개와 400×400 영웅 초상 9개로 구성된다. 변경한 이미지 파일은 동일 이름으로 교체하고 빌드한다. 카드 프레임 위치와 크기는 `local-cards.css`, 그림 표시 규칙은 `painted-art.css`, 확대 창은 `hover-preview.css`가 관리한다. 이전 자체 SVG 그림 코드는 회귀 검사와 대체 제작용으로 보존했다.

## 제작 기록

8개 원본 이미지 묶음을 이미지 생성 도구로 만들었다. 모든 묶음은 글자·카드 프레임·로고 없이 자체 판타지 장면을 그리도록 지정했으며, 원본 게임 리소스를 참조 이미지로 사용하지 않았다. 인물/영웅, 야수/용, 마법/무기, 직업 초상, 강화된 인물 변형, 특수 주문과 괴수, 대표 병사·기사, 기계·악마·정령의 8개 주제다. 정해진 격자에서 각각 잘라 경계 픽셀을 제거하고 정사각형 WebP로 저장했다. 일부 동일 주제 카드에는 같은 그림이 공유되며, 앞으로 개별 그림을 추가할 수 있다.

### v0.28 화풍 기준

- 2014년 판타지 카드게임의 가독성을 참고하되, 완전히 독립적인 디자인. 기존 게임 그림 복제 및 추출 금지.
- 주인공은 그림 면적의 약 75~85%; 억제된 중간톤 회색·갈색의 저세부 배경, 불필요한 입자·후광·번개 제거.
- 개성을 만드는 비대칭 실루엣, 과장된 몸짓과 표정, 가까운 시점, 옆모습, 아래·위에서 올려다보거나 내려다보는 각도 등. 같은 정면 자세 반복 금지.
- 주문과 무기는 효과보다 핵심 물체를 선명하게 표현하고, 필요한 빛과 효과만 사용.
- 카드가 작을 때도 실루엣이 구별되도록 그림의 주요 초점은 중앙 근처에 배치하고 카드/필드의 내부 그림자와 크롭을 완화.

### v0.29 화풍 기준

- 완전히 빈 배경 대신 각 대상의 성격에 어울리는 장소(숲, 성채, 선박, 도서관, 공동묘지 등)를 부드러운 붓질로 표현한다. 배경은 전체의 약 20~35%로, 객체보다 대비와 채도를 낮게 유지한다.
- 주인공은 그림의 약 65~80%를 차지하도록 한다. 피부, 털, 천, 금속, 마법의 색상 차이와 중간 정도로 강한 명암으로 입체감과 형태를 강조한다. 과한 빛 번짐, 네온 윤곽, 입자 효과, 단조로운 갈색/회색 일색은 피한다.
- 각 캐릭터에 다른 체형·얼굴 특징·표정을 부여한다. 웃음, 냉소, 놀람, 당황, 분노 등 감정과 스토리를 담은 포즈를 사용하며, 정면뿐 아니라 아래에서 바라보기, 옆모습, 극단적 근접, 대각선, 원근 왜곡을 활용한다.
- 원작 이미지 복제 없이 독립적인 판타지 회화. 텍스트·카드 프레임·로고는 그림에 포함하지 않는다.
- 새 원본 묶음은 5×5의 정사각 그리드로 만들고, `apps/client/test/art-atlas-import.mjs`에 정의된 15개 묶음의 카드 ID 순서에 맞춘다. 경계를 확인한 뒤 정사각 WebP로 잘라 적용한다. 이 개발용 도구는 ImageMagick이 필요하지만 게임 실행에는 필요 없다.
- `npm run preview:interface` 실행 후 `node apps/client/test/render-preview-images.mjs`로 2개의 화면 배치 PNG 및 대표/전체/영웅/기존 카드 일러스트 JPG를 생성할 수 있다. 후자는 ImageMagick·Inkscape가 있는 개발 환경 전용이다. HTML 미리보기 생성과 게임 실행에는 이 프로그램들이 필요하지 않다.

### v0.30 포인트 색 기준

- v0.29의 캐릭터 디자인·배경·구도·회화풍을 유지한다. 전체 채도, 명도 또는 대비를 일괄 증폭하지 않는다.
- 캐릭터의 개성을 대표하는 시각 요소(눈빛, 머리카락, 표정, 무기 끝부분, 보석, 마법의 작은 핵심 물체 등) 한두 곳만 주변보다 조금 밝고 선명하게 처리한다. 목표 면적은 그림의 약 2~7%이며, 눈에 잘 띄는 강조색은 한두 가지로 제한한다.
- 과도한 광원, 네온, 후광, 발광 효과 추가를 피한다. 배경과 다른 부분은 v0.29의 중간 수준 채도와 명암을 유지한다. 원본과 비교해 개성·포즈 또는 장소가 크게 달라진 결과는 사용하지 않는다.

### v0.31 제작 범위

- v0.30에서 남긴 야수·생물, 주문·무기, 기계·정령의 75종을 개선하여 기존 125종 전체에 포인트 색 기준을 적용했다. 구도·실루엣·배경의 일관성을 유지했다.
- 영웅 등급 카드 38종 모두 전용 그림을 연결한다. 신규 비수집 소환물 그림 2종을 포함해 40개 파일을 추가했다. 추가로 기존 하수인과 주문 50종을 독립적인 그림으로 개선했다.
- 총 215개 로컬 WebP를 사용한다. 기존 346종의 모든 카드가 개별 전용 그림을 가지는 것은 아니며 일부는 그림을 공유한다. 결측 그림은 없다.
- 원작 코드·그림 파일을 다운로드하거나 추출하지 않았으며, 카드 규칙 숫자는 별도 데이터에 유지한다.

### v0.32 카드 프레임 및 그림 중복 제거

- 실제 덱 구성용 카드 346종에 연결된 그림은 이전 197종에서 346종으로 늘었다. 중복 연결 149종에는 각각 별도의 WebP 파일을 할당한다. 기존 그림 215종은 삭제하지 않았다.
- 카드 이미지 칸은 정사각형(1:1), 덱·멀리건·확대 화면의 카드 바깥쪽은 5:8 비율이다. 손패의 공간이 부족할 때는 정사각형을 유지하며 균일하게 축소한다. 큰 그림은 가운데 정렬하고 contain 방식으로 보존한다. 원형·타원형 전장 초상은 기존 형태를 유지한다.
- 새 그림의 제작 순서와 장면 설명은 `apps/client/test/distinct-art-atlases.json`에 기록했다. 6개 묶음의 그림을 독립 셀로 잘랐다. 원본 리소스 추출은 하지 않았다.
- 그림 경로 및 파일의 SHA-256 해시가 346종 모두 별개인지 검사한다. 소환물·동전 등 비수집 카드는 관련 그림을 공유할 수 있다.
- `previews/card-frame-comparison.png`와 `previews/duplicate-art-comparison.png`는 카드 프레임 비율과 독립 그림 연결을 전후 비교한다. `previews/illustrations-distinct.jpg`는 새 그림 149종의 모음이다.
- 색과 인물의 개성을 강화하기 위해 75개의 기존 그림을 재제작했다. 주조색·보조색 조합과 얼굴, 표정의 강도, 자세, 카메라 거리 및 각도를 각각 배정했다. `docs/ART_VARIETY_PLAN.md`에 전체 장면별 계획이 있으며, `previews/art-variety-comparison.png`와 `previews/illustrations-variety-v032.jpg`에서 결과를 확인할 수 있다. 이전 그림은 Git c51c353에 보존했다.
