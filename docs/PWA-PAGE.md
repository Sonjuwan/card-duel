# PWA 페이지 + 로컬 저장 운영 안내

## 지금: PC 로컬 페이지 개발 후보

1. 전체 체크포인트 ZIP을 풀고 `card-duel` 폴더의 `start-offline-app.cmd`를 실행한다. Node.js 24가 설치되어 있어야 한다. ZIP 안에 이미 빌드된 `dist/solo-app/`이 있으면 npm 설치 단계는 필요 없다.
2. 항상 동일 브라우저 프로필에서 `http://127.0.0.1:4179/`를 열어 사용한다. 지원 브라우저에서는 설치 가능한 로컬 앱으로 사용할 수 있다. `solo-offline.html` 직접 실행은 다른 저장 주소이므로 별도 기록이며 실기 확인 전이다.
3. 저장 슬롯 1은 기존 게임을 이어가고, 2/3은 새 성장 또는 기존 별도 기록을 선택한다. 이미 사용한 슬롯을 초기화하지 않는다. 슬롯 전환은 대전 로비에서만 가능하다.
4. 유저 모드 성장 기록 → 성장+덱 통합 백업 다운로드. 저장 덱으로 등록한 것만 포함하며 진행 경기/미저장 편집 덱/연습 전적은 포함하지 않는다. 원래 슬롯에서 게임을 완료하고 백업하는 것을 권장한다.
5. 다른 기기/브라우저 프로필의 미진행 슬롯에서 통합 JSON을 한 번 선택한다. 대상 슬롯/원본 슬롯/추가 예정 덱 수를 확인하고 진행한다. 성장 복원이 완료된 후 저장 덱도 자동 추가한다. 기존 성장과 같은 이름의 다른 덱을 덮어쓰지 않는다. 성장과 덱은 별도 저장소이므로 덱 추가만 실패하면 덱 리스트에서 같은 파일로 재시도한다. 원래 파일은 보관한다.
6. PC 실행기는 시작 시 모든 배포 파일(현재 8개: 서비스 워커 포함)의 전체 해시 및 서비스 워커의 릴리스 ID를 확인한다. 이전 6파일 패키지 역시 무결성을 검증해 실행할 수 있다. 실행 중에는 검증한 파일만 제공하며, 새 ZIP은 다른 폴더에 푼 후 기존 실행기를 닫고 새 실행기를 시작한다. 손상/누락된 패키지는 실행하지 않는다. `node apps/cli/serve-solo-app.mjs --verify`는 서버를 열지 않고 패키지만 확인한다.

## 나중: 모바일에서도 같은 웹페이지 주소

- 모바일의 주소창에 PC의 127.0.0.1 주소를 입력해도 PC 게임에 연결되지 않는다. 모바일 PWA를 설치해 사용하려면 실제 접근 가능한 안전한 HTTPS 정적 사이트 출처가 필요하다. 이 단계는 사용자 승인 후 진행한다. 게임 계정, 데이터베이스, 온라인 대전 서버가 없어도 정적 게임 페이지는 배포할 수 있다. 공개 배포는 내장 카드 정의와 AI 실행 코드/공개용 가중치도 브라우저로 전달하므로 공개 여부를 먼저 결정한다.
- 정적 배포 파일은 `dist/solo-app/`의 여덟 파일뿐이다: `index.html`, `game.js`, `game.css`, `manifest.webmanifest`, `register.js`, `sw.js`, `icon-192.png`, `icon-512.png`. 게임 코드와 그림 스타일은 같은 출처에서 읽고 해시 검증 후 오프라인 캐시한다. Git 프로젝트 원본, AI 학습 체크포인트, 계정 자격증명, 서버 소스는 일반 정적 배포에 포함하지 않는다. 이 폴더를 하나의 완전한 릴리스로 올려야 한다.
- PC/모바일이 같은 페이지를 열어도 기록은 각 기기의 브라우저/저장 원점에 별도로 남는다. 자동 동기화는 계정 연동이 필요하며 현재 보류한다. 기기 이전은 통합 JSON으로 한다.
- 패치는 기존 HTTPS 주소를 바꾸지 않고 파일 전체를 새 릴리스로 교체한다. 서비스 워커는 전체 파일 해시를 검증한 후 기존 창을 닫았을 때 활성화된다. 기존 기록을 자동 삭제하지 않는다. 새 카드 해시로 패치하기 전 진행 중 랭크를 완료하고 성장+덱을 백업한다. 이전 버전의 미완료 랭크가 남아 있는 슬롯은 새 랭크를 시작하지 않도록 보호된다. 동일 주소에서 이전 릴리스를 실행해 경기를 완료한 뒤 최신 릴리스로 복귀한다. 다른 슬롯 및 성장 백업은 이용 가능하다.
- 앱 상단의 패치 확인 버튼으로 검사할 수 있다. 포커스 복귀/네트워크 복구 시에도 60초 간격으로 검사한다. 실패하거나 인터넷이 없으면 현재 버전으로 플레이 가능하다. 새 버전 준비 완료가 표시되면 모든 게임 창을 닫고 다시 열며, 진행 중 랭크보다 업데이트를 우선하지 않는다.
- 실제 Windows/갤럭시 설치·터치·저장·오프라인·업데이트 검증은 `SOLO-ACCEPTANCE.md`를 따라 진행한다. 현재 외부 정적 사이트는 게시하지 않았고 실제 기기 검증도 하지 않았다.
