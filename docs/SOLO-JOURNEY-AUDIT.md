# 솔로 랭크·성장 실전 엔진 검증 — v0.102

이 검사는 새 합성 기록으로 실제 `LocalDuel`의 전투/저장/복원과 `settleOfflineRanked`를 사용한다. 플레이어 역할은 배포 가중치의 최고 AI(25단계), 상대는 실제 해당 랭크 정책 및 전력 덱, 플레이어 덱은 현재 보유 카드와 순서 직업 퀘스트로 생성한다. **사용자 기록/카드/학습 데이터는 쓰지 않는다.** 인간의 승률이나 실기 브라우저 테스트를 의미하지 않는다. 기기 시간 예산과 인스턴스 ID 생성 때문에 같은 시드의 승패가 반드시 동일하다고 보장하지 않는다.

## 재현

- `npm run benchmark:solo-journey -- 96 5100` — 브론즈 5에서 자연 성장, 96경기.
- `npm run benchmark:solo-journey -- 144 7000` — 다른 시드로 자연 성장, 144경기.
- `npm run benchmark:solo-journey -- 25 9000 --all-tiers` — 각 랭크의 독립 합성 시작 프로필에서 1경기씩. 자연 승급 결과가 아니다.
- `npm run progression:simulate -- --json` — 별도 가상 승률 계산(게임 엔진 대전 아님).

매 경기 보유 카드 덱 유효성/랭크에 따른 실제 상대 덱전력·지능/결과 보상/직업 퀘스트/누적 소유 카드 유지/동일 경기 원장 중복 정산 방지를 검증한다. 20·50번째 처리 단계에서 경기 체크포인트 복원 및 동일 데이터 왕복을, 10경기마다 성장 JSON 백업 왕복을 검사한다. 상한(600회 처리 단계) 또는 정상 보상 결과 미생성 시 실패한다.

## 96경기 자연 성장

- 정상 완료 96: 승 56/패 40/무 0, 브론즈 5에서 플래티넘 2(19번째 랭크), 10,915 XP, 341/382종 카드, 9직업 퀘스트 완료 9회(1회 순환 후 다음 직업 6판).
- 실제 전투 6,229 처리 단계, 경기 체크포인트 복원 178회, 성장 백업 왕복 10회. 보유 카드로 합법 덱을 만들었고 결과 및 성장 검증을 모두 통과했다.
- 다이아몬드 1 도달 또는 완전 해금은 이 표본에서 이루어지지 않았다.

## 독립 144경기 자연 성장

- 정상 완료 144: 승 87/패 55/무 2. 브론즈 5에서 **109번째 경기로 다이아몬드 1(25번째 랭크) 승급**, 103경기 시점에 보유 카드 382/382종 해금 확인. 최고 랭크 도달 후 144경기까지 계속 진행했다.
- 최종 다이아몬드 1, 24,086 XP, 보유 카드 382종, 직업 퀘스트 완료 14회(144판), 9직업 모두 플레이. 실제 랭크 1~25에서 각 상대 전투를 완료했다.
- 9,866 처리 단계, 경기 체크포인트 복원 273회, 성장 JSON 왕복 15회. 모든 경기의 XP·소유 카드 보존·퀘스트 반영·원장 중복 정산 거절을 확인했다. 고정 시드의 AI 대리 플레이 결과로 사용자의 실제 승률이나 예상 판수를 확정하지 않는다.

## 독립 25랭크 전투

- 합성 시작 프로필 25개에서 실제 랭크별 상대 덱 전력/지능 1~25 모두 사용, 9직업 플레이어 덱, 정상 완료 25/25(16승 9패).
- 1,804 처리 단계, 경기 체크포인트 복원 46회, 성장 백업 왕복 3회. 실제 모든 랭크의 전투와 보상 경로가 동작했음을 확인했지만 별도 합성 프로필이므로 브론즈에서 다이아까지 자연 진행을 입증한 것은 아니다.

총 자연 성장 240경기 + 독립 랭크 25경기 = 265경기 정상 완료, 처리 단계 17,899회, 경기 체크포인트 복원 497회, 성장 JSON 왕복 28회. 각 검사 기록은 서로 독립이고 사용자 데이터를 대신하지 않는다.

검사 당시 실제 JSON 출력의 진행 지점 및 최종 결과는 `audits/v0102-solo-journey.json`에 보존했다.
