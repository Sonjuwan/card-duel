# 카드 밸런스 시험

## 실행과 수정

1. Windows에서 `start-balance.cmd`를 실행한다. 관리자 도구 주소가 열린다. 게임 서버와 별도의 로컬 전용 도구다.
2. 카드 검색에서 이름 또는 ID를 입력하고 선택한다. 마나, 공격력, 생명력, 내구도, 종족, 키워드, 효과 수치를 변경한다. 간편 효과 추가/제거와 고급 JSON을 이용할 수 있다. 설명은 실제 효과에 맞춰 직접 수정한다.
3. 현재 초안의 카드 수치 분석을 선택한다. 종류와 비용이 같은 카드들의 휴리스틱 중앙값, 이전/현재 수치, 직업별 마나 곡선과 비교 표본을 확인한다. 추정치는 승률이나 균형 판정이 아니다. 동적 할인, 복잡한 효과, 희귀도·직업 시너지 차이는 직접 검토해야 한다.
4. AI 밸런스 시험에서 경기 수와 단계, 시드를 선택한다. 현재 선택 카드 중심 옵션을 켜면 기존 카드가 실험 덱에 포함되도록 하고, 새 카드라면 초안 덱의 가장 비슷한 종류/비용 카드 한 장을 교체한다. 그렇지 않으면 기본 버전의 다양한 전략 덱을 사용한다. 신규 카드는 자동 편입하지 않는다.
5. 시험 시작 시 원본과 초안을 고정한다. 다른 편집을 계속할 수 있으며, 시험 중단은 완료된 묶음의 결과를 유지한다. 브라우저를 새로고침해도 서버가 살아 있으면 결과를 볼 수 있다. 시험 결과는 서버 종료 후 저장되지 않는다.
6. 검토가 끝났다면 저장 전 검사, 새 버전 저장 및 활성화를 누른다. 이전 JSON은 변경하지 않는다. 게임/오프라인 파일을 새 밸런스로 재시작/빌드하려면 README를 참고한다.

## 시험 해석

- 한 묶음은 원본 2경기와 초안 2경기, 총 4경기다. 동일 시드와 동일 덱으로 좌석을 바꾸므로 선후공 편향을 줄인다. 새 카드 집중 시험에는 기준 덱과 카드 한 장만 바꾼 덱을 사용한다.
- 36, 108, 216경기는 각각 9, 27, 54묶음이다. 6/11/18단계의 고정 정책 1과 기본 가중치, 제한된 탐색 노드를 사용해 재현 가능하게 한다. 학습 데이터에 영향을 주지 않는다.
- 실험 덱 승점률은 승리 1점, 무승부 0.5점, 패배 0점을 가능한 최대 점수로 나눈 수치다. 양쪽 카탈로그의 모든 경기가 끝난 유효 묶음만 포함한다. 별도의 직업 승률은 완료된 경기에서 직업별 승리 수/그 직업의 관측 경기 수다. 같은 직업끼리 대결하면 양쪽 관측을 계산한다.
- 카드의 덱 포함, 손패 관측, 플레이 횟수는 플레이어-경기 단위다. 생성 카드도 손패에서 관측될 수 있고 버려지거나 즉시 소모된 카드가 누락될 수 있다. 카드 사용 후 승률의 분모는 해당 카드를 1회 이상 사용한 완료 경기다. 원인/결과 관계로 해석하면 안 된다. 표본 부족, 게임 승패의 여러 영향, 특정 덱과 AI의 한계를 고려한다.
- 600행동 제한을 넘긴 경기는 통계 모수에서 제외하고 별도 표시한다. 한 묶음 안의 일부 게임이 제한되면 실험 덱 승점 비교에서도 그 묶음을 제외한다. 서버는 단일 Worker만 실행하므로 편집기 API를 차단하지 않는다.

## CLI 재현 (저장된 버전)

`npm run balance:sim -- --from v0.22.0.json --to v0.23.0.json --pairs 9 --level 11 --seed 20241122`

출력은 JSON이며 stderr에 진행이 표시된다. `--focus wolf`로 특정 카드에 집중할 수 있다. 현재 활성 버전, 원본 파일, AI 체크포인트는 수정하지 않는다.
