# 전설 전용 일러스트 v0.37.0

경로: `apps/client/src/assets/illustrations/legend-*.webp`. 각 새 카드가 전용 300×300 WebP 파일을 갖는다. 원작 카드 이미지가 아닌 독립 생성 그림 63개를 7개의 3×3 원시 시트로 제작하고, 타일 경계 2px를 잘라 낸 뒤 축소했다. 각 시트는 텍스트·카드 테두리 없이 정사각형, 은은한 장소 배경, 뚜렷한 실루엣, 개성을 드러내는 지점에만 색상과 명암을 강조했다.

| 시트 | 대상 |
|---|---|
| 1 | 그롬마쉬, 알아키르, 에드윈, 티리온, 왕 크루쉬, 세나리우스, 자락서스, 안토니다스, 벨렌 |
| 2 | 탈노스, 초, 밀하우스, 내트, 무클라, 땜장이, 늙은 거먹눈, 그린스킨, 해리슨 |
| 3 | 리로이, 케른, 흑기사, 실바나스, 들창코, 일리단, 게돈, 그룰, 라그나로스 |
| 4 | 알렉스트라자, 말리고스, 노즈도르무, 오닉시아, 이세라, 데스윙, 겔빈, 정예 타우렌 족장, 괴수 |
| 5 | 세나리우스 나무정령, 파멸의 인도자, 피의 격노, 지옥불정령, 바나나, 데빌사우루스, 다람쥐, 리로이 새끼용, 바인 |

구도는 정면 얼굴에 집중하는 대신 측면·후면·낮은 시점·상향 시점·전신 움직임·클로즈업을 혼합했다. 같은 카드 사본을 제외하면 382개 덱 구성 카드의 일러스트 연결은 중복이 없음을 검사한다. 원시 시트는 편집 중간 자료이며 배포 시 개별 파일만 사용한다.
