## 배포 챔피언 대비 비교

`npm run benchmark:research -- 9 release`는 16개 행에 각 9쌍씩 총 144쌍(288경기)을 실행했다. 기록된 배포 챔피언은 6,848경기·276세대·승격 0회이며 현재 가중치 지문이 공통 기본값과 같았다. 상대 확률을 혼합한 연구 후보는 147승 141패(51.04%), 무승부와 상한 도달은 각각 0경기였다. 각 행은 해당 직업·덱 조건에서 정방향과 역방향의 후보를 한 쌍으로 집계했다.

| 첫 좌석 / 둘째 좌석 | 어그로 | 미드레인지 | 컨트롤 | 빅덱 |
| --- | ---: | ---: | ---: | ---: |
| 어그로 | 38.9% | 55.6% | 44.4% | 50.0% |

마지막 후보 결정의 전략 추론 정확도는 동점 분할 집계로 94.56%, 단일 경기 기준 다중분류 Brier 점수는 평균 0.4608이었다. 균등 예측의 Brier 점수는 0.75이다. 추론에 사용한 참조 덱과 시험 덱이 같은 생성 규칙을 쓰므로 독립·실전 덱에 일반화한 결과는 아직 없다. 이 표본에서 가중치의 우월성과 고난도에서의 효과는 미검증이다.

새 학습 루프, CPU·온도 자동 제어, Windows CMD 및 독립 배포 ZIP의 수용 테스트는 구현·검증 대기 상태다.

## 공개 행동 추론과 전술 회귀

별도 시드와 구간별 덱 구성으로 홀드아웃 288경기(중단 0)를 실행했다. 검증 덱의 같은 직업·전략 참조 덱과의 겹침은 30장 중 평균 10.70장, 최대 18장이었다. 다음 표의 Brier 점수는 낮을수록 좋다. 정확도는 동점 후보 수로 배분했다. 6라운드 전에 끝난 게임은 해당 라운드의 표본에서 제외했다.

각 자리 교대 시험은 576경기, 정책 2·난이도 6·24노드에서 진행했다. 행동 포함 대 카드 ID는 290승 286패(50.35%, 쌍 bootstrap 95% 49.65~51.04%). 카드 특성 대 균등 혼합은 289승 287패(50.17%, 49.31~51.04%). 행동 포함 대 카드 특성은 288승 288패(50.00%, 49.48~50.52%). 완료된 각 비교에 무승부·중단은 없었다. 검증용 덱은 별도 생성 규칙을 사용했으며 실제 사용자 덱은 표본에 포함되지 않았다.

정책 2·3의 3연속 도발 돌파와 공개 정보 제한을 재현했다. 고정 반격 상황에서 기본 가중치의 정책 3은 공격력 6 하수인을 제거했고 정책 2는 다음 공격에 패배했다. 정책 3도 컨트롤의 균등·어그로 편중 혼합으로 같은 공격에 패배했다. 정책 변경이나 가중치 혼합을 일반적으로 안전하다고 볼 수 없다.
