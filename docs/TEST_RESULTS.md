## 배포 챔피언 대비 비교

`npm run benchmark:research -- 9 release`는 16개 행에 각 9쌍씩 총 144쌍(288경기)을 실행했다. 기록된 배포 챔피언은 6,848경기·276세대·승격 0회이며 현재 가중치 지문이 공통 기본값과 같았다. 상대 확률을 혼합한 연구 후보는 147승 141패(51.04%), 무승부와 상한 도달은 각각 0경기였다. 각 행은 해당 직업·덱 조건에서 정방향과 역방향의 후보를 한 쌍으로 집계했다.

마지막 후보 결정의 전략 추론 정확도는 동점 분할 집계로 94.56%, 단일 경기 기준 다중분류 Brier 점수는 평균 0.4608이었다. 균등 예측의 Brier 점수는 0.75이다. 추론에 사용한 참조 덱과 시험 덱이 같은 생성 규칙을 쓰므로 독립·실전 덱에 일반화한 결과는 아직 없다. 이 표본에서 가중치의 우월성과 고난도에서의 효과는 미검증이다.

새 학습 루프, CPU·온도 자동 제어, Windows CMD 및 독립 배포 ZIP의 수용 테스트는 구현·검증 대기 상태다.
