# 개발 순서 및 재개 규칙

사용자 결정: 혼자 AI와 대전하는 완성도 우선. 단계가 검증 완료되면 다음 단계에 바로 착수한다.

2026-11-23 최신 우선순위: AI 25단계 차등 조정보다 별도 PC 학습 프로그램으로 최고 실력을 확보한다. 게임 개발은 솔로 웹 UX, PC/모바일 호환, 저장·패치, 전투 UI/이미지/사운드/타격감·접근성·성능 순으로 지속한다. 완료 단계 뒤에는 실제 결함이나 개선점을 스스로 분석하여 다음 작업에 착수한다. 기존 AI 학습 원본·정규 정책·카드 밸런스 유지, 신규 온라인 계정/PvP 및 배포 보류. 야간에는 정각 중단 대신 검증된 체크포인트 저장 후 다음 작업을 이어간다.

### 지속 품질 개선 순서 (최신)

1. 저장·패치·솔로 진행의 회귀를 계속 확인한다. 기록이 손상되거나 다른 탭에서 점유할 때는 새 기록으로 덮어쓰지 않는다.
2. PC/모바일 조작과 가독성: 전투판 및 카드/덱 상세의 좁은 화면 표시, 키보드 포커스, 긴 누르기/스크롤·드래그, 긴 설명과 결과/백업 UI. 물리 기기 또는 Chromium 권한 문제로 막히면 테스트 코드를 남기고 비슷한 다른 결함부터 수정한다.
3. 전투 감각: 실제 판정 기반의 명확한 시각/음향, 중복·취소된 연출 방지, 정상/빠름/즉시 및 모션 감소 접근성, 화면/기기별 렌더 예산. 실기 FPS나 체감은 직접 측정 전 주장하지 않는다.
4. 이미지: 기존 427개 일러스트 및 카드 식별성을 보존하며 누락/중복/잘못된 자르기·저대비를 먼저 조사한다. 전투에서 중요한 영웅/무기/카드 상태를 명확하게 보이는 개선부터 시작한다. 새 비트맵 생성 시 원본과 대조하고 오프라인 패키지 크기 및 에셋 완전성을 검사한다.
5. 장기 진행 UX와 재플레이: 성장·전적/퀘스트 표시, 저장 실패 안내, 덱 편집/검색·추천, 솔로 재대전 등을 실제 사용자 흐름 중심으로 검증한다. 게임 밸런스·기본 AI 학습은 수정하지 않는다.
6. 각 단계의 실제 결함과 검증 결과를 근거로 다음 작업을 선택한다. 기존 기능 및 백업을 유지하고 자동 회귀/렌더/웹 빌드와 패치 호환 검사 후 체크포인트를 기록한다.

새로운 대형 모드는 사용자와 범위를 합의한 뒤 개발한다.

작업 구간마다 한국 시간(Asia/Seoul)을 확인한다. 최신 사용자 요청에 따라 야간 중에는 정각에 검증된 기능, 테스트 수/실패 및 원인, 진행 중인 기능, 다음 작업, 재시작 방법과 버전을 기록한 뒤 가능한 다음 작업을 계속한다. 작업 시작·구현 완료·테스트·Git/ZIP 백업 전환 시 실제 시각과 작업 상태를 진행 메시지로 표시한다. 사용자가 `ㄱㄱ`만 입력하면 이 문서와 `docs/PROGRESS.md`, 최신 Git 상태를 확인해 미완료 지점부터 바로 재개한다. 도구/실행 환경 제약 때문에 먼저 종료되는 경우 실제 작업 시간과 중단 이유를 밝힌다. 예약 재개는 실행이 보장되지 않으므로 성공을 지어내지 않는다. 사용자의 추가 중단 요청은 우선한다.

각 안정 버전에서 가능한 한 Git 기록 및 ZIP 체크포인트를 만든다. 과거 데이터 파일, 사용자 카드 밸런스, `data/ai` 학습 파일을 삭제하거나 덮어쓰지 않는다. 새로운 AI는 기존 결과를 후보로 받아 새 환경에서 성능 확인 후 채택한다.
