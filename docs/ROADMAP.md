# 개발 순서 및 재개 규칙

사용자 결정: 혼자 AI와 대전하는 완성도 우선. 단계가 검증 완료되면 다음 단계에 바로 착수한다.

1. 전설 카드 36종/토큰/일러스트 및 1장 제한 — v0.37.0 완료(실기 브라우저는 별도)
2. AI 2.0 학습 계승: 과거 가중치와 스냅샷 보존, 신규 카드 및 밸런스에서 재평가 — 기능 구현 및 이식/재개 테스트 완료, v0.38.0
3. AI 2.0 범용화: 다양한 덱·카드 밸런스 무작위화, 과거 우수 모델 리그, 진화 후보와 엄격한 평가 — v0.39.0 구현 완료, 장기 성능 검증 별도
4. AI 2.0 성능/기기 최적화: 노트북 CPU 모드, 기기 Worker, 오프라인 실행, 25단계 시간 벤치마크 — v0.40.0 기능 구현 완료, 실제 S24/Windows 성능과 25단계 승률 평가 별도
5. 솔로플레이 개선: AI 덱 다양화, 매치 설정, 결과/재대전(기기 AI), 전략적 덱 구성 — v0.41.0 기능 구현 완료
6. 전투 UI/애니메이션 효과와 모바일 조작/가독성 개선 — v0.42.0 기능 구현, 물리 모바일 및 브라우저 검증 별도
7. 카드 판정·밸런스 분석·편집기 개선 및 통합 플레이테스트 — v0.43.0 기능과 1,225경기 시험 완료, 역사적 개별 카드 판정 및 물리 브라우저는 추가 검증
8. 온라인 안정화(후순위) — v0.44.0 재접속·시간 제한 일시정지·방 정리·요청 복구 구현. 실제 원격 네트워크 시험은 별도.

9. 솔로 대전 저장/이어하기 — v0.45.0 코드 및 자동 회귀 검증 완료 후보, 실제 브라우저 IndexedDB/Windows/S24 확인 미완료.
10. 실기 성능 및 솔로 UX, 독립 AI 강도 검증·개선 — 호스트 성능/독립 난이도 평가 착수. 실기는 실제 기기에서 별도 측정한다.
11. 카드 판정 세부 회귀 시험.

새로운 대형 모드는 사용자와 범위를 합의한 뒤 개발한다.

작업 구간마다 한국 시간(Asia/Seoul)을 확인한다. `ㄱㄱ` 입력 시 다음 짝수 시각 정각(00, 02, 04, …, 12, 14, …, 22시)에 새 작업 착수를 멈추고 검증된 기능, 테스트 수/실패 및 원인, 진행 중인 기능, 다음 작업, 재시작 방법과 버전을 기록한다. 사용자가 `ㄱㄱ`만 입력하면 이 문서와 `docs/PROGRESS.md`, 최신 Git 상태를 확인해 미완료 지점부터 바로 재개한다. 도구/실행 환경 제약 때문에 먼저 종료되는 경우 실제 작업 시간과 중단 이유를 밝힌다. 사용자의 추가 중단 요청은 우선한다.

각 안정 버전에서 가능한 한 Git 기록 및 ZIP 체크포인트를 만든다. 과거 데이터 파일, 사용자 카드 밸런스, `data/ai` 학습 파일을 삭제하거나 덮어쓰지 않는다. 새로운 AI는 기존 결과를 후보로 받아 새 환경에서 성능 확인 후 채택한다.
