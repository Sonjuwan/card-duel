# 다른 인터넷망의 친구와 플레이 (선택적 무료 방법)

v0.44부터 연결이 끊기면 5분 동안 진행을 중지한다. 같은 탭에서 자동 재연결 또는 연결 재시도 버튼을 이용하면 이전 손패와 전장이 복원된다. 상대가 없으면 턴 제한도 일시 중지된다. 한 명만 연결된 경우 5분 후 서버가 상대의 패배를 처리하고, 둘 다 없으면 방을 정리한다. 대기/종료 방은 30분 후 정리된다. 방 생성 응답이 누락되었을 때에도 클라이언트 탭의 비공개 요청 번호로 복구한다. 서버 프로그램 자체가 종료되면 메모리의 온라인 방은 여전히 복구할 수 없다.

현재 서버는 LAN 또는 사설 네트워크에서 사용할 수 있는 개발 버전이다. 요금제 가입이나 운영 서버 없이 한 컴퓨터가 경기 서버를 실행한다. 외부 인터넷 실기 테스트는 아직 시행하지 않았다. 아래는 설정 안내이며 배포·VPN 계정 등록을 완료했다는 의미가 아니다.

## 추천: Tailscale 사설 연결

2026-11-21 확인한 공식 자료에서 개인 비상업적 사용을 위한 무료 요금제와 사설 노드 공유를 제공한다. 두 플레이어 모두 계정 및 프로그램 설치가 필요하지만, 게임 자체의 필수 구성요소는 아니다. 유료 신청이나 결제 정보 입력은 필요하지 않도록 무료 Personal 요금제를 선택한다.

공식 출처:

- [무료 요금제](https://tailscale.com/docs/account/manage-plans/free-plans-discounts)
- [Windows 설치](https://tailscale.com/docs/install/windows)
- [사설 게임 호스트 공유](https://tailscale.com/docs/use-cases/personal-or-at-home-use/share-private-game-server)
- [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve)

### A. 먼저 게임 자체의 정상 동작 확인

1. `start-game.cmd`를 실행한다(기본 주소 `http://127.0.0.1:3000`).
2. 브라우저 일반/시크릿 창에서 두 명의 대전을 시작하고 적어도 멀리건, 턴 이동, 카드 소환과 공격을 확인한다.
3. 서버 터미널을 열어 둔다. 게임 서버와 관리자 편집기는 분리되어 있으며 외부에 관리자 주소를 공유하지 않는다.

### B. 친구와 사설 VPN 연결

1. 호스트와 친구의 PC에 [Tailscale Windows](https://tailscale.com/download/windows)를 설치하고 각자 자신의 계정으로 로그인한다.
2. 공식 사설 게임 서버 공유 지침에 따라 게임을 호스팅하는 노드에만 신뢰하는 친구에게 접근 권한을 준다. 가능하면 접근 제어 정책에서 게임 포트만 허용한다. 호스트 PC의 다른 서비스나 다른 노드에 대한 필요 없는 권한을 부여하지 않는다.
3. 호스트 PC의 Tailscale IPv4 주소(일반적으로 `100.64.0.0/10` 범위)를 확인한다. 이는 예시 범위이고 실제 주소는 프로그램에서 확인해야 한다.
4. 게임 서버를 종료하고 `start-lan.cmd`를 실행하여 그 IPv4를 입력한다. 서버가 표시하는 `http://해당주소:3000`을 친구에게 전달한다(방 코드와 함께). 친구가 그 주소로 접속하여 방에 참가한다.

이 방법에서는 게임 서버가 지정한 사설 인터페이스에만 바인딩된다. VPN 연결에서 통신을 암호화한다. 사설 VPN이 정상적으로 연결되고 노드/포트 권한이 맞아야 한다. 친구의 PC에서 접속하지 못하면 서버 콘솔, Tailscale 연결 여부, 호스트 방화벽 및 접근 정책을 확인한다. 방화벽 전체를 끄지 않는다.

### C. 선택: 사설 HTTPS 프록시(고급)

호스트에서 로컬 전용 `start-game.cmd`를 실행한 채 별도 터미널에서 `tailscale serve 3000`으로 사설 HTTPS 주소를 받을 수 있다. 친구에게 접근 권한을 부여한 동일 사설 네트워크에서만 사용한다. 공식 문서의 HTTPS 설정 안내를 따른다. `tailscale funnel`은 공개 인터넷에 노출할 수 있으므로 사용하지 않는다.

만약 프록시를 통해 브라우저 WebSocket 출처 검증에 실패한다면 서버를 종료하고 PowerShell에서 실제 Serve 주소의 정확한 출처(경로와 마지막 슬래시 없음)를 설정한다. 아래 주소는 예시일 뿐이며 사용자의 실제 주소가 아니다.

```powershell
$env:CARD_DUEL_PUBLIC_ORIGIN = 'https://your-device.your-tailnet.ts.net'
npm.cmd run web
```

서버는 이 출처 하나만 추가로 허용한다. 와일드카드 출처 사용이나 출처 검사 해제는 하지 않는다. 관리자 포트 3001은 프록시 대상으로 사용하지 않는다. 플레이 종료 후 서버와 Serve의 포그라운드 터미널을 `Ctrl+C`로 종료한다.

## 남은 실기 검증

실제 다른 인터넷망의 두 Windows 컴퓨터로 접속, 멀리건, 소환, 공격, 재접속, 항복을 검증해야 한다. 현재 개발 환경에서는 localhost Socket.IO 연결 두 개 및 출처 검증을 자동 테스트했다. VPN 계정·사용자 권한·네트워크 설정은 실제 사용자 환경에서만 완료할 수 있다.
