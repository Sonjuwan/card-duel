# AI 2.0 개발 보류 계획

2026-11-22 사용자 결정: 솔로플레이 우선, 전설 카드 구현 이후 AI 2.0, 이후 게임 개선, 온라인 안정화는 뒤로 둔다. 현재 학습 결과는 반드시 보존한다.

| 차수 | 예상 작업량 | 목표 |
|---|---|---|
| 1 | 2시간 | 학습 데이터 영구 보존, 카드 버전 간 이식, 보편적 평가 |
| 2 | 2시간 | 진화 알고리즘, 과거 우수 AI 리그, 다양한 덱과 가상 밸런스 |
| 3 | 2시간 | 노트북 CPU 병렬 탐색, 캐시, 리소스/발열 제어 |
| 4 | 2시간 | 로컬 브라우저 AI, 갤럭시 S24 기준 성능 검증, 25단계 강도 비교 |

학습 기준: 사용자 노트북 GTX 1650 Ti, RAM 16GB. 유료 API 없이 CPU 우선. 카드 데이터의 원본은 절대 변경하지 않고 학습 중 가상 변형만 사용한다. 다른 카드 환경에서는 이전 가중치를 초기 후보로 가져와 별도 검증하며 과거 체크포인트를 덮어쓰지 않는다.

플레이 기준: S24에서 60 FPS 목표, 복잡한 AI 판단도 5초 이내 목표. 실제 기기 실측 필요. AI가 상대의 숨은 덱/손패/비밀 및 서버 RNG를 보지 않도록 유지. 1~25단계는 그대로 지원하고 높은 난이도에 더 큰 탐색 예산을 적용한다. 실제 승률의 단조성/인간 수준은 검증 전 보장하지 않는다.

v0.38.0에서 과거 챔피언 자동 후보 이식, 다른 프로젝트 폴더의 AI 파일 import, 체크포인트 이식 및 조회, 원본 보호, 대상 카드 버전에서 독립 검증 완료 후 채택 기능을 구현했다. v0.39.0은 전략별 덱 7가지, 실제 원본을 수정하지 않는 가상의 수치 및 효과 변형, 과거 챔피언 리그, 엄격한 검증 기준을 구현했다. 실제 10시간 성능 시험과 노트북/휴대폰 실기 성능 검증은 이후 단계이다.

v0.40.0: CPU 학습 모드별 워커·휴식·체크포인트 정책, 기기 내 Worker 전투 및 AI, 시간/노드 예산, 단일 파일 오프라인 게임을 추가했다. 개발 호스트 32개 전투 포지션 × 25단계 800회에서 25단계 p95 96ms, 최대 113ms, 불법 행동 실패 0회. 성능 비교가 아닌 처리량 실험이며 S24 실측은 아직 없다.
