# 첫 플레이와 오류 확인 안내 (Windows 11)

이 문서는 프로그래밍을 처음 접하는 플레이테스터용이다. 별도 유료 API, GPU 설정, 일러스트 다운로드는 필요하지 않다.

## 1. 한 번만 준비

1. Node.js 24.x Windows x64 설치 파일을 https://nodejs.org/ 에서 내려받아 설치한다.
2. Card Duel ZIP의 압축을 풀고 `card-duel` 폴더를 연다. 압축 파일 안에서 직접 실행하지 않는다.
3. `start-game.cmd`를 더블클릭한다. 처음에만 인터넷을 통해 무료 npm 의존성을 설치한다. 검은 창을 닫지 않고 실행 주소가 나올 때까지 기다린다.
4. Chrome 또는 Edge에서 http://127.0.0.1:3000 을 연다. 카드 수와 직업 선택이 표시되면 준비 완료다.

## 2. AI 대전 먼저 하기

1. 추천 덱을 그대로 사용하거나 내 직업을 선택한다.
2. 대전 메뉴의 AI 영역에서 AI 직업과 난이도 1단계(입문) 또는 3단계(보통)를 고른다.
3. AI 대전 시작을 누른다. 교체할 시작 카드를 선택하고 확정한다.
4. 내 턴에 녹색 윤곽의 카드를 클릭한다. 대상이 필요한 카드는 금색 윤곽의 하수인 또는 영웅을 선택한다. 하수인 배치 위치는 내 전장의 금색 틈을 선택한다. 손패 하수인을 원하는 틈으로 직접 끌어 놓을 수도 있다. 공격자는 클릭 후 대상 클릭, 또는 상대 대상에게 직접 드래그로 공격한다. Esc/우클릭으로 선택 취소. 카드에 마우스를 올리면 왼쪽에 해당 능력과 제한 사유가 나타난다.
5. 하수인 공격 또는 영웅 능력을 사용하고 오른쪽 턴 종료를 누른다. AI 턴이 끝나면 다시 내 턴이 된다.
6. 현재 경기의 승패, 탈진, 과부하, 사용 카드와 피해 기록을 확인할 수 있다. 종료 후 덱 편집으로 돌아간다.

AI 난이도는 기존 5단계이며 이번 버전에서 판단 성능을 학습시키거나 변경하지 않았다.

### 새 전장 확인 (v0.27.0)

- AI와 친구 대전 모두 새 자체 회화형 그림을 사용하며 인터넷 이미지 요청은 없다. 화면의 마나·효과·공격력·생명력이 실제 게임 값이다. 오른쪽 상단 이름 전환 버튼은 한글 표시명만 변경한다.
- 내 손패·내 전장·상대 전장의 공개 카드에 마우스를 1초 이상 올려 큰 카드와 설명이 뜨는지 확인한다. 1초 전에 마우스를 떼면 뜨지 않아야 한다. 다른 카드로 이동하면 새로 1초를 기다리고, 마우스를 떼거나 Esc, 클릭, 드래그를 하면 닫혀야 한다. 피해를 입은 하수인과 버프된 하수인의 현재 수치가 표시되어야 한다.
- F11 전체화면에서 카드 1~10장의 부채꼴 정렬, 카드 마우스 확대, 하수인 7개까지의 공간, 영웅 및 무기 위치, 오른쪽 턴 종료와 마나 수정을 확인한다.
- 덱 편집 화면에서는 전체, 기본 카드, 오리지널 카드 탭을 선택한다. 기본 탭에서 기본 카드만, 오리지널 탭에서 일반/희귀 카드만 표시되는지 확인한다. 8장씩 페이지를 넘기거나 필터 및 검색으로 모든 합법 카드를 확인할 수 있다.
- 화면 구도가 어색하거나 카드 선택이 어려우면 브라우저 배율과 해상도를 함께 기록한다.

## 3. 핵심 규칙 플레이테스트 목록

| 확인할 항목 | 기대 동작 |
|---|---|
| 멀리건 | 선공 시작 3장, 후공 4장. 교체 후 시작 준비. 후공은 동전 받음 |
| 마나 | 매 턴 최대 마나 1 증가, 최대 10. 내 턴 시작 시 채워짐 |
| 하수인 | 돌진이 없으면 낸 턴에는 공격 불가. 전장 최대 7개 |
| 공격 | 도발부터 공격. 상대 은신 하수인을 직접 공격하지 못함 |
| 주문 | 대상이 필요한 경우만 선택. 주문 공격력 적용 |
| 무기 | 장착하고 영웅 공격 사용. 내구도 0이면 파괴 |
| 비밀 | 상대는 종류를 모르고 개수만 봄. 조건에서 이름 공개 및 발동 |
| 종족 | 같은 종족 또는 해당 조건의 카드 능력 발생 |
| 동시 피해 | 동시에 여러 하수인 사망, 죽음의 메아리 소환 |
| 게임 종료 | 영웅 체력 0 승패, 동시 사망 및 최대 턴 무승부, 항복 |

## 4. 직접 덱 만들기 및 공유

1. 대전 메뉴에서 직업을 선택하고 **덱 편집하기**를 누른 뒤, 필요하면 비우기를 누른다.
2. 검색/종류/등급/비용/직업 필터로 카드를 찾는다. 카드를 눌러 추가하고, 오른쪽 덱 목록을 눌러 제거한다. 평균 마나와 종류별 장수로 덱 구성을 확인한다. 빈칸 자동 채우기는 기존 카드를 그대로 유지하며 30장을 완성한다. 되돌리기는 최근 변경을 취소하며, 새로고침해도 현재 초안은 저장된다.
3. 정확히 30장(같은 카드 최대 2장)이면 덱 저장 버튼과 대전 버튼을 사용할 수 있다.
4. 덱 이름을 입력해 저장한다. 친구와 덱 공유하기를 열고 공유 코드를 생성해 복사한다. 친구는 동일한 카드 버전에서 코드를 붙여넣고 불러온다.
5. v0.16.0 이전의 개발용 카드가 포함된 덱은 호환되는 카드만 복원한다. 원래 저장 덱은 보존된다.

## 5. 친구와 대전 확인

1. 일반 브라우저 창과 시크릿 창을 연다. 각각 http://127.0.0.1:3000 에 접속한다.
2. 한 창에서는 새 방 만들기, 다른 창에서는 6자리 방 코드 입력 후 참가.
3. 두 창에서 시작 카드를 확정한다. 선공부터 행동한다.
4. 같은 경기에서 상대 손패 이름과 덱 순서를 볼 수 없어야 한다.
5. 내 브라우저를 새로고침해 현재 상태로 복귀하는지 확인한다.
6. 같은 Wi-Fi의 다른 PC 또는 서로 다른 장소에서의 대전은 README 및 REMOTE_PLAY.md에 따라 별도로 실기 확인한다.

## 6. 카드 수치 하나 바꾸고 다시 돌려놓기

1. 게임은 종료하거나 현재 경기만 끝낸다.
2. `start-balance.cmd`를 더블클릭한다. http://127.0.0.1:3001 을 연다.
3. 카드 검색창에 `flame_sphere`를 입력한다. 마법사 주문 화염 구체를 선택한다.
4. 간편 효과 수치 편집에서 피해량 6을 7로 바꾼다. 카드 설명도 피해 7로 바꾼다.
5. 저장 전 검사를 눌러 통과를 확인한다. 이 단계에서는 카드 파일이 아직 바뀌지 않는다.
6. 새 버전 저장 및 활성화를 누른다. `balance-...` 파일이 생성된다. 이전 버전과 비교 버튼으로 차이를 확인한다.
7. 게임 서버를 종료하고 `start-game.cmd`를 다시 실행한다. 카드 정보를 다시 불러온 브라우저에서 피해 7을 확인한다.
8. 다시 원상 복구하려면 관리자에서 `v0.21.0.json`을 선택하고 활성화한 뒤 게임 서버를 재시작한다. 이번 수정 버전 파일 또한 남아 있다.

현재 카드 복제해서 새 카드 만들기를 통해 새 카드를 추가할 수도 있다. 새 ID를 지정하고 능력치를 수정한 뒤 같은 검사/저장 절차를 진행한다. 원작 대응 범위를 유지하려면 기본 v0.21.0을 사용한다.

## 7. 자동 검사

`test-game.cmd`를 실행하면 TypeScript 검사, 활성 카드 감사, 자동 테스트, 웹 빌드 및 React 서버 렌더링 검사를 차례로 수행한다. 모든 검사 성공 표시를 확인한다.

추가 명령:

```powershell
npm.cmd run audit
npm.cmd run stress -- 100
npm.cmd run demo
```

실제 브라우저 자동 테스트(선택):

```powershell
npx.cmd playwright install chromium
npm.cmd run test:browser
```

Linux 개발 환경에서는 Chromium 실행이 권한 문제로 막혀 실제 화면 자동 검증을 완료하지 못했다.

## 8. 오류를 발견했을 때 기록할 내용

- 어떤 버전에서 발생했는지 (관리자 현재 버전, 또는 README 버전)
- 내 직업, 상대 직업, AI 난이도 또는 친구 대전
- 카드 이름 및 문제 발생 전 순서
- 예상 결과와 실제 결과, 전투 기록 및 화면 캡처
- 자동 검사 오류인 경우 콘솔의 마지막 오류 줄 및 재현 명령

실시간 대전 화면 하단의 **오류 신고용 전투 기록**을 펼쳐 **전투 기록 복사**를 누르면 최근 60개의 공개 전투 기록, 양쪽 공개 전장 능력치 및 카탈로그 해시를 복사할 수 있다. 방 코드, 손패의 이름, 덱 순서, 비밀 정체는 포함하지 않는다. 복사 기능을 지원하지 않는 브라우저에서는 선택된 텍스트를 Ctrl+C로 복사할 수 있다.

자동 대전에서 문제가 발생하면 출력되는 `npm run stress -- 1 경기번호` 명령으로 해당 시드 경기를 재현할 수 있다. 별도 학습이나 유료 서비스가 필요 없다.
