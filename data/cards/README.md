# 카드 데이터

`v0.1.0.json`은 초기 하수인 15종, `v0.2.0.json`은 46종, `v0.3.0.json`은 카드 정의 60개, `v0.4.0.json`은 90개, `v0.5.0.json`은 106개, `v0.6.0.json`은 118개, `v0.7.0.json`은 131개, `v0.8.0.json`은 137개(덱 구성 가능 135종 + 토큰 2종), `v0.11.0.json`은 201개(덱 구성 가능 194종 + 토큰 7종)이다. v0.8.0부터 마법사 기본 10개의 기준 규칙을 대조했고 v0.11.0에서 나머지 8개 직업 기본 80종을 대응 구현했다. 자세한 대응표는 `docs/ROSTER_PLAN.md`를 참조한다.

하수인은 `id`, `name`, `kind`, `class`, `rarity`, `cost`, `attack`, `health`, `tribe`, `description`을 가진다. 주문/무기/비밀은 종류별 필드를 가진다. 카드 효과 JSON은 `docs/EFFECTS.md`를 참조한다.

v0.16.0은 개발용 카드도 포함하는 이전 버전이다. 사용자가 특별히 활성화하지 않는 한 현재 덱에 편입할 수 없다. 이전 덱 복원 기능은 원본 저장 덱을 유지한다. 관리자에서 원본 카드를 복제해 새 카드를 추가하거나 두 저장 버전을 읽기 전용으로 비교할 수 있다.

기존 버전 파일은 보존한다. `npm run balance`로 새 버전을 저장하면 새 `balance-...json`이 만들어지고 `active.json`이 갱신된다. 게임 서버 재시작 시 활성 버전이 적용된다. 기존 버전에서 재현 가능한 테스트는 고정 버전을 참조하고, 경기마다 카탈로그 스냅샷이 보존된다.
