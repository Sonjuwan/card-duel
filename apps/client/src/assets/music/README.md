# Card Duel background score
Original synthesized recordings created for the integrated UI release. The source instrumentation is layered harmonic strings, plucked strings and, for preparation and battle, percussion. The files are stereo MP3 so the web and offline builds share the same recordings. There are no third-party loops or recordings.

Home, preparation, collection, deck editing, victory and defeat each use their own track. The five numbered battle tracks use a shuffle bag.
