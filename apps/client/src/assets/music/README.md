# Card Duel v0.301 soundtrack

Original composition and sequencing are in [render-score.py](../../../../../scripts/audio/render-score.py). Rendering uses FluidSynth, FFmpeg and Debian's TimGM6mb General MIDI SoundFont. The 24 kHz stereo MP3 files use 48 kb/s. The installable app downloads the needed scene on demand and verifies the entire score during offline installation. The one-file HTML embeds the same recordings.

TimGM6mb SoundFont credits Tim Brechbill and David Bolton and is distributed under GPL-2. The SoundFont binary is supplied by the render host and is excluded from this repository. The Debian package publishes the upstream and sample provenance. https://packages.debian.org/stable/timgm6mb-soundfont · https://sources.debian.org/src/timgm6mb-soundfont/
